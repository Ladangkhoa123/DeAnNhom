What is MUSICWAVE?+

MUSICWAVE is a music discovery concept that brings songs, artists, albums, playlists, charts, and music stories together in one place.

Can I listen to music for free?+

This website is a static HTML and CSS demo. It showcases music discovery and a player interface, but it does not stream or play audio.

How do I find a song?+

Use the search field near the top of the page, or browse trending songs, artists, albums, charts, and genres.

How do I create a playlist?+

Playlist creation is not connected in this front-end demo. Explore the featured playlists to see how playlist cards are presented.

Can I use MUSICWAVE on my phone?+

Yes. The layout adapts to phone, tablet, laptop, and desktop screens using CSS media queries.
